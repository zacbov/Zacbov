1. Coller le code

Colle une ou plusieurs fonctions function creerXxx(){...}. Auto-sauvegardé dans ce navigateur. Si plusieurs fonctions sont détectées, celles marquées 🧊 construisent probablement un vrai modèle 3D (elles créent un Mesh/Group et le retournent) — commence par elles.
L'analyse essaie de construire chaque fonction candidate toute seule (avec des valeurs par défaut) et ne te montre que celles qui fonctionnent réellement — tu n'as qu'à cliquer dessus.
