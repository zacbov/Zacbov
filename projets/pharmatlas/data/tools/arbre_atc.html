🌳 Arbre ATC

Classification anatomique, thérapeutique et chimique — cinq niveaux
Que signifie ce code ?
Comment se lit un code ATC
NiveauExempleCe qu'il désigne
1NGroupe anatomique principal — l'organe ou le système visé
2N02Sous-groupe thérapeutique
3N02BSous-groupe pharmacologique
4N02BESous-groupe chimique
5N02BE01Substance chimique
Une même substance peut porter plusieurs codes selon l'indication ou la voie d'administration : l'acide acétylsalicylique est en N02BA01 comme analgésique et en B01AC06 comme antiagrégant plaquettaire.
Ce que couvre la base
Cet arbre ne montre que les codes présents dans PharmAtlas, pas la classification ATC complète de l'OMS. Une branche vide ici n'est pas une branche vide de la classification : c'est une branche sans médicament dans la base.
